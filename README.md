# SEA Motion Starter

قالب محلي قابل للرفع إلى GitHub لإنتاج درس كامل من تسجيل المحاضر والأنيميشن التعليمي بهوية SEA.

## التشغيل

يتطلب Node.js وفق engines في package.json.

```sh
npm ci
npm run check
npm run studio
```

افتح العنوان الذي يظهر، ثم SEA-Lesson. المثال 30 ثانية، صامت، ويستخدم سلايد الأكاديمية بدل تسجيل محاضر. ليس درسًا نهائيًا.

## إدخال درس حقيقي

1. ضع التسجيل داخل public/recordings مثل lesson-01.mp4.
2. عدّل lessons/lesson.json: لكل مقطع source مثل recordings/lesson-01.mp4، وsourceIn بداية الجزء في التسجيل الأصلي بالثواني، وduration مدة الجزء الذي تريد الاحتفاظ به.
3. المقاطع تُجمع بالترتيب بدون فجوات. حذف جزء يتم باستبعاده من قائمة المقاطع. لا توجد إزالة صمت تلقائية.
4. cues داخل كل مقطع: start من بداية الجزء بعد القص، وduration مدة الأنيميشن. مثلًا sourceIn=40 وcue.start=3 يعني ظهور الأنيميشن عند الثانية 43 من التسجيل الأصلي.
5. تغيير sourceIn يستلزم إعادة مراجعة توقيت cues. تغيير ترتيب مقطع ينقل معه الأنيميشن. صوت الفيديو يبقى مستمرًا تحت المشاهد الكاملة.
6. استخدم تفريغًا بتوقيتات بعد مراجعة الكلمات والمصطلحات. القالب لا يحتوي حاليًا على تفريغ تلقائي أو اختيار ذكي تلقائي للأنيميشن.
7. راجع الفيديو والصوت في المعاينة، خصوصًا حدود القص. تأكد أن sourceIn + duration لا يتجاوز طول المصدر؛ فحص الملفات الحالي لا يقيس مدة التسجيل.

## مكتبة الأنيميشن

| type       | الاستخدام                              |
| ---------- | -------------------------------------- |
| chapter    | عنوان فصل بخلفية كحلية                 |
| steps      | كشف خطوات تدريجي                       |
| equation   | نص الشرح والمعادلة ثم النتيجة          |
| comparison | مقارنة مفاهيم                          |
| focus      | تحديد مساحة في التسجيل وتعتيم ما حولها |
| callout    | ملاحظة قصيرة فوق التسجيل               |

title عنوان المشهد. lines حتى 3 سطور قصيرة. equation يضيف formula وresult. focus يحتاج x,y,w,h كنسب مئوية من الكادر النهائي.
التوقيتات التجريبية ليست مزامنة مع كلام محاضر. يمكن تغيير تأخيرات ظهور العناصر داخل src/Motion.tsx بما يناسب الجملة.
تعديل المحتوى والتوقيت مركزيًا في JSON؛ المعاينة ليست محرر مونتاج تقليديًا يعيد كتابة كل مقطع مستقل.

## التصدير

```sh
npm run render
```

الناتج out/lesson.mp4. أبعاد 1920×1080 و30 إطارًا/ثانية. راجع النتيجة كاملة بعد التصدير.
لا يوجد تسجيل محاضر مرفق. جرّب أولًا مقطعًا حقيقيًا قصيرًا لاختبار جودة الصوت والمزامنة قبل درس طويل.

## طلب جاهز لأي مساعد

اقرأ AGENTS.md وSTYLE.md. التسجيل في public/recordings/lesson-01.mp4. حلّل الشرح، واكتب خطة القص والأنيميشن بتوقيتات حقيقية، ثم جهّز الدرس بهوية SEA. حافظ على صوت المحاضر. استخدم حركة تخدم المعنى، واعرض المعاينة للمراجعة.

## الملفات

- src/Motion.tsx: مكونات الأنيميشن.
- src/Lesson.tsx: تجميع الفيديو والصوت والأنيميشن.
- lessons/lesson.json: محتوى الدرس وقائمة القص.
- public/brand: الخط واللوجو.
- public/recordings: التسجيلات المحلية، مستبعدة من Git.
- STYLE.md وAGENTS.md: الهوية وطريقة عمل المساعد.
